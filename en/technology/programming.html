Programming is the writing of instructions that a computer can execute.[1] These instructions, called source code, are written in a programming language and describe step by step what the computer must do. In this encyclopedia, the subject refers mainly to web development, the creation of websites and web applications, which relies on three core languages: HTML, CSS and JavaScript. A program can also read a sensor or control a motor, which links software to the physical world, as in automation.

Web languages

Every web page is built from three layers, each with its own language.[2][3][4]

The three core web languages
LayerLanguageRoleExample
StructureHTMLDefines the content and its meaning: headings, paragraphs, links and lists<h1>Title</h1>
PresentationCSSControls the appearance: colours, fonts and layouth1 { color: navy; }
BehaviourJavaScriptAdds logic and interaction in the browserdocument.title = "Hello";

Keeping the three layers separate applies the principle of separation of concerns, which divides a program into parts that each handle one responsibility.[5] A change of appearance then requires a change only in the CSS, not in the HTML. Semantic HTML supports this principle by using elements such as header, nav, main and article, which describe the meaning of the content rather than its appearance.

Clean code

Clean code is code that other people, and the author at a later date, can read and change with little effort. Common practices are:

  • Meaningful names: variables and functions are named after what they represent.
  • Small functions: each function does one thing.
  • No repetition: each piece of knowledge is stated once, a rule known as don't repeat yourself.[6]
  • Useful comments: comments explain why a decision was made, not what the code already says.
  • Consistent formatting: indentation and style are uniform across the project.

Study approach

Programming skill comes from building, so small projects teach more than reading alone. A practical path is:

  1. Write a static page in HTML, then style it with CSS.
  2. Add one interaction with JavaScript, such as a button that changes a text.
  3. Read the error messages and use the developer tools of the browser to find the cause of a problem; finding and fixing errors is called debugging.
  4. Record every change with a version control system such as Git,[7] so that earlier versions can be restored.

Learning first the few concepts that appear in almost every program, such as variables, conditions, loops and functions, gives the greatest return for the time spent.
