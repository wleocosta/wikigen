Программирование

Эта статья входит в категорию Технологии.

Программирование
КатегорияРазработка программного обеспечения
Основной фокусВеб-разработка
Веб-языкиHTML, CSS, JavaScript
Ключевой принципЧистый код
Связанные темыАвтоматизация, финансы

Программирование — написание инструкций, которые может выполнить компьютер.[1] Эти инструкции, называемые исходным кодом, пишутся на языке программирования и шаг за шагом описывают, что должен делать компьютер. В этой энциклопедии под предметом понимается главным образом веб-разработка — создание сайтов и веб-приложений, которая опирается на три основных языка: HTML, CSS и JavaScript. Программа может также считывать показания датчика или управлять двигателем, что связывает программное обеспечение с физическим миром, как в автоматизации.

Веб-языки

Каждая веб-страница строится из трёх слоёв, у каждого из которых свой язык.[2][3][4]

Три основных веб-языка
СлойЯзыкРольПример
СтруктураHTMLОпределяет содержимое и его смысл: заголовки, абзацы, ссылки и списки<h1>Заголовок</h1>
ПредставлениеCSSУправляет внешним видом: цветами, шрифтами и компоновкойh1 { color: navy; }
ПоведениеJavaScriptДобавляет логику и взаимодействие в браузереdocument.title = "Привет";

Разделение этих трёх слоёв применяет принцип разделения ответственности, который делит программу на части, каждая из которых отвечает за одну задачу.[5] Изменение внешнего вида тогда требует правки только CSS, а не HTML. Семантический HTML поддерживает этот принцип, используя такие элементы, как header, nav, main и article, которые описывают смысл содержимого, а не его внешний вид.

Чистый код

Чистый код — это код, который другие люди, а также сам автор спустя время могут читать и изменять без больших усилий. Распространённые практики:

  • Осмысленные имена: переменные и функции называются по тому, что они представляют.
  • Небольшие функции: каждая функция делает одно дело.
  • Без повторений: каждая часть знания записывается один раз — правило, известное как не повторяйся (DRY, don't repeat yourself).[6]
  • Полезные комментарии: комментарии объясняют, почему принято решение, а не то, что код уже говорит.
  • Единообразное форматирование: отступы и стиль одинаковы во всём проекте.

Подход к изучению

Навыки программирования приходят через создание, поэтому небольшие проекты учат больше, чем одно чтение. Практический путь таков:

  1. Написать статичную страницу на HTML, а затем оформить её с помощью CSS.
  2. Добавить одно взаимодействие с помощью JavaScript, например кнопку, которая меняет текст.
  3. Читать сообщения об ошибках и использовать инструменты разработчика в браузере, чтобы найти причину проблемы; поиск и исправление ошибок называется отладкой.
  4. Записывать каждое изменение в системе контроля версий, такой как Git,[7] чтобы можно было восстановить прежние версии.

Если сначала изучить немногие понятия, встречающиеся почти в каждой программе, — переменные, условия, циклы и функции, — отдача от потраченного времени будет наибольшей.
